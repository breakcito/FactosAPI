Listar documentos

Retorna los documentos de la empresa paginados. Soporta filtros por establecimiento, fecha, tipo y estado.

GEThttps://api.facturalo.pe/api/v3/empresas/documentos

Query params

ParamTipoDescripción
establecimientoopcionaluuidFiltra por establecimiento.
fecha_inicioopcionaldatefecha_emision >= valor. Formato YYYY-MM-DD.
fecha_finopcionaldatefecha_emision <= valor. Formato YYYY-MM-DD.
limiteopcionalintCantidad de resultados. Default 20, máx 100.
tipoopcionalstring01 = Factura · 03 = Boleta · 07 = NC · 08 = ND.
estadoopcionalstringACEPTADA · RECHAZADA · ANULADA · PENDIENTE_RESUMEN · etc.

Paginación

CampoDescripción
totalTotal de documentos que coinciden con los filtros.
limiteCantidad de resultados por página.
paginaPágina actual.
paginasTotal de páginas disponibles.
Requestjson
// Sin body — GET request
GET /empresas/documentos?tipo=03&fecha_inicio=2026-06-01&fecha_fin=2026-06-30&limite=20
