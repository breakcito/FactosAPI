SIRE

El Sistema Integrado de Registros Electrónicos (SIRE) permite gestionar el Registro de Ventas e Ingresos (RVIE) y el Registro de Compras Electrónico (RCE) directamente en SUNAT, sin necesidad de ingresar al portal manualmente.

Requisito previo: Para usar cualquier endpoint de SIRE debes configurar las credenciales SOL de tu empresa en la sección de datos de la empresa: Client ID, Client Secret, Usuario SOL y Clave SOL. Sin estas credenciales los endpoints retornarán un error de autenticación.

Todos los endpoints de SIRE operan directamente contra producción SUNAT — no existe entorno de pruebas. Puedes usar tu token sk_test_* o sk_live_* indistintamente.

¿Cómo funciona la conexión con SUNAT?

Facturalo se conecta automáticamente a SUNAT usando tus credenciales SOL cada vez que consumes un endpoint de SIRE. No necesitas gestionar tokens ni sesiones — solo asegúrate de tener las credenciales configuradas correctamente en tu empresa.
