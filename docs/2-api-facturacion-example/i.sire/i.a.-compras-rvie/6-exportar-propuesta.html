Exportar propuesta

Genera un ticket para exportar la propuesta de compras. El archivo estará disponible en Base64 al consultar el ticket.

GEThttps://api.facturalo.pe/api/v3/sire/compras/{periodo}/exportar

Respuesta exitosa

200 OKjson
{
  "success": true,
  "message": "Exportación iniciada. Consulte el estado con el numTicket.",
  "data": {
    "numTicket": "20260300000141"
  }
}
Con el numTicket recibido, consulta el endpoint Descargar propuesta hasta que el archivo esté listo para descargar.
