Comprobantes

Lista paginada de los comprobantes de compras incluidos en la propuesta SUNAT para el período.

GEThttps://api.facturalo.pe/api/v3/sire/compras/{periodo}/comprobantes

Parámetros

periodo
stringrequerido
Período tributario YYYYMM.Ej: 202606
page
numberopcional
Página. Default: 1.Ej: 1
perPage
numberopcional
Registros por página. Máx: 100. Default: 100.Ej: 100
