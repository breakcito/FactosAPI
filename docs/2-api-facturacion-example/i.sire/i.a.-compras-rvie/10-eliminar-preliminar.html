Eliminar preliminar

Revierte el período de estado Preliminar a Propuesta.

PUThttps://api.facturalo.pe/api/v3/sire/compras/{periodo}/eliminar-preliminar

200 OKjson
{
  "success": true,
  "message": "Preliminar eliminado correctamente.",

}

200 OKjson

  "success": true,
  "message": "El período ya se encuentra en etapa propuesta.",

    "numTicket": null
  }
}
