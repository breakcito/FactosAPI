Periodos

Lista los períodos tributarios de compras disponibles y su estado ante SUNAT.

GEThttps://api.facturalo.pe/api/v3/sire/compras/periodos
Requisito previo: Para usar SIRE debes configurar las credenciales SOL de tu empresa: Client ID, Client Secret, Usuario SOL y Clave SOL. Puedes hacerlo en la sección de datos de tu empresa. Sin estas credenciales el endpoint retornará un error de autenticación.
