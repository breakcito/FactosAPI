Preliminares registrados

Consulta si el período tiene un preliminar registrado. Úsalo para obtener el id necesario antes de revertir con Eliminar preliminar registrado.

GEThttps://api.facturalo.pe/api/v3/sire/ventas/{periodo}/preliminares

Parámetros

periodo
stringrequerido
Período tributario YYYYMM.Ej: 202605
page
numberopcional
Página. Default: 1.Ej: 1
perPage
numberopcional
Registros por página. Default: 100.Ej: 100
