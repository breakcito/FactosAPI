Descargar propuesta

Descarga el archivo de la propuesta generado con Exportar propuesta. Consulta el estado hasta que el archivo en Base64 esté disponible.

GEThttps://api.facturalo.pe/api/v3/sire/ventas/tickets/{numTicket}/descargar

Mientras procesa

200 OKjson
{
  "success": true,
  "message": "El proceso aún no ha terminado. Reintente en unos segundos.",
  "data": {
    "numTicket": "20260300000133",
    "codEstadoProceso": "05",
    "desEstadoProceso": "En proceso",
    "terminado": false,
    "expirado": false
  }
}

Ticket expirado

200 OKjson
{
  "success": false,
  "message": "El ticket expiró sin completarse. Vuelva a ejecutar la exportación para generar uno nuevo.",
  "data": {
    "numTicket": "20260300000133",
    "codEstadoProceso": "EXP",
    "desEstadoProceso": "Expirado",
    "terminado": false,
    "expirado": true
  }
}
Cuando expirado: true, vuelve a llamar GET /sire/ventas/{periodo}/exportar para obtener un nuevo numTicket.
