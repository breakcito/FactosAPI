Resumen de comprobantes

Desglose de la propuesta por tipo de comprobante (Facturas, Boletas, NC, ND) con totales de base imponible, IGV y monto.

GEThttps://api.facturalo.pe/api/v3/sire/ventas/{periodo}/resumen-comprobantes

Parámetros

periodo
stringrequerido
Período tributario YYYYMM.Ej: 202606
tipo
numberopcional
1=propuesta, 2=preliminar, 3=no incluidos, 4=registro. Default: 1.Ej: 1
