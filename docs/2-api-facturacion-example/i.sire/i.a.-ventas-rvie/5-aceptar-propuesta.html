Aceptar propuesta

Acepta la propuesta de ventas de SUNAT tal cual y avanza el período a Preliminar Registrado.

POSThttps://api.facturalo.pe/api/v3/sire/ventas/{periodo}/aceptar-propuesta
¡Atención! Esta acción se ejecuta directamente en SUNAT y mueve el período a Preliminar Registrado. Si necesitas revertirlo, usa el endpoint Eliminar preliminar registrado antes de que el período avance a un estado irreversible.
