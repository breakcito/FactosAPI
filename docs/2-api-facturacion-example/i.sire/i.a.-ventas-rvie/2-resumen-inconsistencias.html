Resumen de inconsistencias

Muestra el porcentaje de comprobantes con errores en la propuesta. Revísalo antes de aceptar para asegurarte de que la propuesta está limpia.

GEThttps://api.facturalo.pe/api/v3/sire/ventas/{periodo}/resumen

Parámetros

periodo
stringrequerido
Período tributario en formato YYYYMM.Ej: 202606
tipo
numberopcional
1=propuesta, 2=preliminar, 3=no incluidos, 4=registro generado. Default: 1.Ej: 1
