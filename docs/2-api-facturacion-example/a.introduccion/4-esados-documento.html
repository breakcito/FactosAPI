¿Cuáles son los posibles estados de un documento SUNAT?

Todos los documentos tienen un campo estado que refleja el resultado del procesamiento con SUNAT. Esta tabla describe cada valor posible.

EstadoDescripción
EN_PROCESOEl documento fue recibido y está siendo procesado por SUNAT.
ACEPTADASUNAT aceptó el comprobante correctamente.
RECHAZADASUNAT rechazó el comprobante. Revisa sunat.codigo y sunat.mensaje para el detalle del error.
ANULADAEl comprobante fue anulado exitosamente ante SUNAT.
PENDIENTE_RESUMENBoleta en espera de ser incluida en el Resumen Diario (RC). Consulta nuevamente el estado para ver el resultado final.
BAJA_RECHAZADASUNAT rechazó la Comunicación de Baja (RA). La factura no fue anulada.
