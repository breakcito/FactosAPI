Anular Factura

Anula una factura electrónica ya aceptada por SUNAT mediante una Comunicación de Baja (RA). El proceso es síncrono: la respuesta incluye la confirmación de SUNAT.

POSThttps://api.facturalo.pe/api/v3/documentos/anular
Solo se pueden anular facturas emitidas el mismo día o hasta 7 días después de la fecha de emisión. Para facturas fuera de ese plazo, utiliza una Nota de Crédito.

Parámetros del body

documento
objectrequerido
Datos del comprobante a anular.
tipoComprobante
stringrequerido
Debe ser "01" para Factura.
serie
stringrequerido
Serie de la factura.Ej: F001
correlativo
stringrequerido
Número correlativo.Ej: 1
motivo
stringrequerido
Razón de la anulación.Ej: Error en los datos del cliente
