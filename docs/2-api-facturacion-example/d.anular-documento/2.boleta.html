Anular Boleta

Anula una boleta electrónica mediante Resumen Diario (RC). La anulación se envía inmediatamente a SUNAT, pero la respuesta puede ser inmediata o requerir consulta posterior.

POSThttps://api.facturalo.pe/api/v3/documentos/anular
SUNAT puede devolver la respuesta de forma inmediata o de forma diferida. Si el estado es PENDIENTE_RESUMEN, consulta el resultado en GET /documento/{id}/estado.

Parámetros del body

documento
objectrequerido
Datos del comprobante a anular.
tipoComprobante
stringrequerido
Debe ser "03" para Boleta.
serie
stringrequerido
Serie de la boleta.Ej: B001
correlativo
stringrequerido
Número correlativo.Ej: 1
motivo
stringrequerido
Razón de la anulación.Ej: Error en los datos del cliente

{
