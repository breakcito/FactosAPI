Listar eventos webhook

Retorna todos los eventos disponibles y su estado (activo/inactivo) por entorno.

GEThttps://api.facturalo.pe/api/v3/empresas/{uuid}/webhook/eventos

Parámetros del request

Authorization
header · stringrequerido
Token de empresa (sk_test_... o sk_live_...).Ej: sk_test_...

Parámetros del response

data
objectrequerido
Eventos por entorno.
demo
arrayrequerido
Lista de eventos del entorno demo.
evento
stringrequerido
Nombre del evento (ej: documento.sunat.respuesta).
activo
booleanrequerido
true si el evento está activo y se enviará al webhook.
prod
arrayrequerido
Lista de eventos del entorno de producción.
evento
stringrequerido
Nombre del evento.
activo
booleanrequerido
true si el evento está activo.
