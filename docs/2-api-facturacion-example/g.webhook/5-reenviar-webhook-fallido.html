Reenviar webhook fallido

Reenvía el payload original de un webhook fallido. Solo acepta eventos con tipo documento.webhook.fallido o documento.webhook.reintento. Se reenvía el payload exacto guardado en base de datos.

POSThttps://api.facturalo.pe/api/v3/webhooks/{eventoId}/reenviar

Parámetros del request

Authorization
header · stringrequerido
Token de empresa (sk_test_... o sk_live_...).Ej: sk_test_...

Parámetros del response

data
objectrequerido
Confirmación del reenvío.
evento
stringrequerido
Nombre del evento reenviado.
documentoId
stringrequerido
ID del documento asociado.
