Listar webhooks enviados

Retorna el historial de webhooks enviados. Filtra por estado o evento para encontrar envíos fallidos y reenviarlos.

GEThttps://api.facturalo.pe/api/v3/webhooks

Parámetros del request

Authorization
header · stringrequerido
Token de empresa (sk_test_... o sk_live_...).Ej: sk_test_...
estado
query · stringopcional
Filtra por estado: "FALLIDO" · "OK".Ej: FALLIDO
evento
query · stringopcional
Filtra por tipo de evento.Ej: documento.sunat.respuesta
per_page
query · intopcional
Registros por página. Default: 20.Ej: 20
page
query · intopcional
Página a consultar. Default: 1.Ej: 1
