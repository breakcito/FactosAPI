Guía remitente — transporte público

Emite una Guía de Remisión Remitente (serie T..., tipo 09) para transporte público. Requiere datos de la empresa transportista (RUC) y la fecha de entrega de bienes.

POSThttps://api.facturalo.pe/api/v3/guias/enviar

Parámetros del request

webhook
booleanopcional
true = respuesta asíncrona vía webhook (recomendado). false = espera la respuesta de SUNAT en el mismo request (puede tardar varios segundos). Default: false.Ej: true
guia
objectrequerido
Datos de la guía de remisión.
enviarCorreo
booleanopcional
Si es true, envía el PDF y XML al correo del destinatario tras la aceptación. Default: false.Ej: true
fechaEmision
stringrequerido
Fecha de emisión en formato YYYY-MM-DD.Ej: 2026-06-14
serie
stringrequerido
Serie de 4 caracteres. T... = Guía Remitente (tipo 09).Ej: T001
correlativo
stringrequerido
Correlativo numérico.Ej: 128
tipoTransporte
stringrequerido
"01" = Transporte público · "02" = Transporte privado.Ej: 01
motivoTraslado
stringrequerido
"01" = Venta · "02" = Compra · "04" = Traslado entre almacenes · "08" = Importación · "09" = Exportación.Ej: 01
observaciones
string | nullopcional
Observaciones del traslado.Ej: ENTREGA DE MERCADERÍA SEGÚN ORDEN DE COMPRA
cliente
objectrequerido
Datos del destinatario de los bienes.
tipoDocumento
stringrequerido
"6" = RUC · "1" = DNI.Ej: 6
numeroDocumento
stringrequerido
RUC (11 dígitos) o DNI (8 dígitos).Ej: 20100070970
denominacion
stringrequerido
Razón social o nombre.Ej: EMPRESA DISTRIBUIDORA SAC
correo
string | nullopcional
Correo del destinatario.Ej: compras@empresa.com
datosTraslado
objectrequerido
Datos del traslado.
fecha
stringrequerido
Fecha de inicio del traslado. YYYY-MM-DD.Ej: 2026-06-14
fechaEntregaBienes
string | nullopcional
Requerida si tipoTransporte = 01 (público).Ej: 2026-06-14
pesoBrutoTotal
numberrequerido
Peso bruto total de los bienes.Ej: 150.5
pesoUnidadMedida
stringrequerido
"KGM" = kilogramos · "TNE" = toneladas.Ej: KGM
numeroBultos
numberrequerido
Número total de bultos o paletas.Ej: 10
indicadorDeEnvio
string | nullopcional
Indicador de envío.Ej: 01
datosTransportista
objectrequerido
Datos de la empresa transportista. Requiere RUC.
tipoDocumento
stringrequerido
Debe ser "6" (RUC).Ej: 6
numeroDocumento
stringrequerido
RUC del transportista (11 dígitos).Ej: 20415932376
denominacion
stringrequerido
Razón social del transportista.Ej: TRANSPORTES RÁPIDOS SAC
numeroMTC
string | nullopcional
Número de registro MTC del transportista.Ej: MTC-123456
puntoPartida
objectrequerido
Punto de origen del traslado.
ubigeo
stringrequerido
Código INEI de 6 dígitos.Ej: 150101
direccion
stringrequerido
Dirección del punto de partida.Ej: AV. INDUSTRIAL 123, LIMA
puntoLlegada
objectrequerido
Punto de destino del traslado.
ubigeo
stringrequerido
Código INEI de 6 dígitos.Ej: 040101
direccion
stringrequerido
Dirección del punto de llegada.Ej: JR. COMERCIO 456, AREQUIPA
items
arrayrequerido
Bienes trasladados.
codigo
stringrequerido
Código del producto.Ej: PROD-001
descripcion
stringrequerido
Descripción del bien.Ej: TELEVISOR LED 55 PULGADAS
unidadMedida
stringrequerido
Código SUNAT de unidad.Ej: NIU
cantidad
numberrequerido
Cantidad de unidades trasladadas.Ej: 5
documentosRelacionados
array | nullopcional
Comprobantes relacionados al traslado (facturas, boletas, guías).
tipoDocumento
stringrequerido
"01" = Factura · "03" = Boleta · "09" = Guía remitente · "31" = Guía transportista.Ej: 01
numeroDocumento
stringrequerido
Número completo del documento.Ej: F001-00000123
