Tipos de operación SUNAT

Código de operación requerido por SUNAT. Se envía en el campo sunatTransaccion del documento.

documento.sunatTransaccion
CódigoNombre
0101
Venta interna

El más común. Facturas y boletas gravadas, exoneradas, inafectas.

0102
Venta interna — anticipos
0104
Venta interna — anticipos (primer pago)

Usar para la primera factura/boleta de anticipo.

0200
Exportación

Usar con tipoIgv: 40 y moneda: USD.

0401
Ventas no domiciliados que no califican como exportación
1001
Operación sujeta a detracción

Requiere el objeto detraccion en el payload.

1002
Detracción — Recursos hidrobiológicos
1003
Detracción — Servicios de transporte de pasajeros
1004
Detracción — Servicios de transporte de carga
2001
Operación sujeta a percepción

Requiere el objeto retencion en el payload.
