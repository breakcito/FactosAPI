Histórico de tipo de cambio SBS en un rango de fechas

Authorizations:

query Parameters
from
required
string <date>
Example: from=2026-09-01

Fecha inicial del rango (YYYY-MM-DD), inclusive.

to
required
string <date>
Example: to=2026-09-05

Fecha final del rango (YYYY-MM-DD), inclusive. Máximo 366 días desde 'from'.
