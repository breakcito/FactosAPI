Último tipo de cambio SBS (o el de una fecha específica)

Sin parámetros devuelve el último registro disponible. Con date, devuelve el registro de ese día exacto o 404 si no existe.

Authorizations:
bearerAuthtokenQueryParam
query Parameters
date
string <date>
Example: date=2026-09-04

Fecha exacta a consultar (YYYY-MM-DD). Sin este parámetro, se devuelve el último registro disponible.
