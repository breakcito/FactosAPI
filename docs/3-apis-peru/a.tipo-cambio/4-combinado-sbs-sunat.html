SBS y SUNAT en una sola respuesta

Evita tener que llamar a /sbs y /sunat por separado. date aplica a ambas fuentes; cada una puede tener o no datos para esa fecha de forma independiente (revisa el success de cada sub-objeto).

Authorizations:
bearerAuthtokenQueryParam
query Parameters
date
string <date>
Example: date=2026-09-04

Fecha exacta a consultar (YYYY-MM-DD). Sin este parámetro, se devuelve el último registro disponible.
