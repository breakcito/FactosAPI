Tipo de Cambio API (1.0)

Download OpenAPI specification:Download

URL: https://apisperu.com

Tipo de cambio (compra/venta) de USD, CAD y EUR en Perú, según SBS y SUNAT. Los datos se actualizan automáticamente todos los días hábiles (ver /todos, /sbs y /sunat) y se pueden consultar históricamente.

Autenticación: todos los endpoints de esta página requieren un token (Authorization: Bearer <token>, o ?token= como alternativa). El token se genera desde tu panel en apisperu.com/admin/tipocambio (requiere una cuenta gratuita en apisperu.com) — esta API no tiene registro propio.
